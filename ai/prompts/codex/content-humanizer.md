# Content Humanizer Prompt

Use this when storefront copy sounds too polished, abstract, or AI-generated.

## Prompt

Review the changed customer-facing copy in the SES ICT HUB storefront.

Rewrite it so it sounds like a real Nairobi electronics shop assistant:

- Clear
- Calm
- Practical
- Trustworthy
- Human

Prefer:

- Message us on WhatsApp and one of our team will assist you.
- We can help you confirm before you buy.
- Pickup available at our Moi Avenue shop.
- We will confirm before dispatch.

Remove or rewrite:

- Hype
- Fake urgency
- Journey or flow language
- Software marketing language
- Copy that explains the interface instead of helping the buyer

Check:

```bash
npm run content:check
npm run copy:check
```
