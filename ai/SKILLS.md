# Codex Skills

Use project skills only when they match the task.

## Preferred

- `frontend-skill`: homepage, category pages, product pages, mobile UX, and storefront copy
- `playwright`: browser route checks and conversion-flow validation
- `cloudflare-deploy`: Wrangler auth, Worker deploys, and release checks
- `spreadsheet`: CSV imports, price updates, and catalog QA
- `security-best-practices`: auth, admin, and API hardening review
- `sentry`: production error visibility and post-deploy debugging

## Secondary

- `figma`: when a Figma file or node link is provided
- `notion-spec-to-implementation`: when work starts from a Notion spec

## MCP Use

Use MCP tools only when needed to inspect, verify, modify, or deploy real project resources.

Before using MCP:

1. Explain why the tool is needed.
2. Prefer local project files first.
3. Do not modify production data without explicit approval.
4. Never invent results from MCP tools.
5. If a task can be completed from existing files and instructions, do not use MCP.
