# Prompt Library

Reusable Codex prompts live in `ai/prompts/codex/`.

Use these when you want a repeatable task shape:

- `build-component.md` for a new or changed UI component
- `refactor-route.md` for an Astro page or API route refactor
- `content-humanizer.md` for shop-assistant copy cleanup
- `audit-repo.md` for a local repo review
- `csv-cleaner.md` for catalog CSV cleanup
- `image-matching.md` for product image matching work

Each prompt assumes the project guardrails in `ai/AGENTS.md`, `ai/GUARDRAILS.md`, and `ai/BRAND.md`.
