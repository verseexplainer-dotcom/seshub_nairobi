# Content Rules

Customer-facing text should sound like a practical Nairobi electronics shop.

## Use

- Clear stock wording
- Plain CTA labels
- Helpful WhatsApp support language
- Product facts from the database
- Short sentences that fit mobile cards

## Avoid

- Hype
- Fake urgency
- SaaS wording
- Process words like journey, flow, optimize, seamless, shortlist, or switch
- Unsupported claims about reviews, popularity, guarantees, or delivery

## WhatsApp Copy

Prefer:

- If you need help, message us on WhatsApp.
- One of our team will assist you.
- We can help you confirm before you buy.

Avoid:

- Switch to WhatsApp.
- Use conversational commerce.
- Continue your purchase flow.

## Checks

Run:

```bash
npm run content:check
npm run copy:check
```
