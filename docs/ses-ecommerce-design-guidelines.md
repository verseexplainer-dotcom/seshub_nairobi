# SES E-commerce Design Guidelines

These guidelines are for improving the SES ICT Hub e-commerce website into a cleaner, more professional, Shopify-style refurbished laptop store.

## Store style

Use a clean electronics e-commerce style:

- White or very light grey page background
- Dark navy text
- SES blue primary buttons
- Soft rounded cards
- Subtle borders
- Gentle shadows
- Clean spacing
- Large consistent product images
- Simple badges
- Clear specs
- Clear trust messaging
- Mobile-first layout

## Homepage recommendations

The homepage should guide buyers and build trust, not only show products.

Recommended homepage structure:

1. Hero section
   - Headline: Quality Refurbished Laptops in Kenya
   - Supporting text: tested devices, warranty, Nairobi pickup, countrywide delivery
   - Primary CTA: Shop Laptops
   - Secondary CTA: WhatsApp Us or Contact Us
   - Use a clean laptop image, product collage, or existing product image area

2. Trust section
   - Tested Devices
   - Warranty Included
   - Nairobi Pickup
   - Countrywide Delivery

3. Featured categories
   - Dell Laptops
   - HP Laptops
   - Lenovo Laptops
   - Core i5 Deals
   - Core i7 Deals
   - Budget Laptops

4. Featured deals
   - Use a section such as "Today's Best Laptop Deals"
   - Keep it curated and not overloaded
   - Use improved product cards

5. Why buy from SES
   - Every device is tested before sale
   - Warranty included
   - Clear refurbished condition
   - Pickup in Nairobi
   - Countrywide delivery
   - WhatsApp support

6. Refurbished explanation
   - Explain refurbished laptops in friendly, reassuring language

## Shop page recommendations

The shop page should support easy browsing and comparison.

Product grid:

- Keep mobile-first
- Two columns on mobile are acceptable if cards remain readable
- Design product grids mobile-first: use 2 columns on small screens where practical, then widen the grid on desktop
- Product images should be dominant
- Avoid cramped content
- Keep enough space between cards
- Prioritize laptops, smartphones, printers, and desktops in the main browsing flow

Useful filters if supported:

- Brand
- Processor
- RAM
- Storage
- Price range
- Condition
- Availability

Useful sorting if supported:

- Newest
- Price low to high
- Price high to low
- Best deals

Do not build a large filter system from scratch unless the project already supports it.

## Product card requirements

Product card hierarchy:

1. Product image
2. Badges: Refurbished and In Stock
3. Brand/category
4. Product title
5. Key specs
6. Price
7. Old/compare price
8. One savings/discount message only
9. Add to Cart button

Each product card must clearly show:

- Image
- Category
- Product name
- Price
- Stock state
- A clear action

Comparison, specs, and trust content should stay easy to scan and never feel crowded.

Visual rules:

- Use a square image area, ideally 1:1
- Use object-fit: contain for laptops
- Product image should visually fill about 75-85% of the image area where possible
- Use a clean white or very light grey image background
- Use consistent padding and rounded corners
- Use subtle borders and soft shadows
- Keep category text small
- Product title should allow up to two lines
- Do not truncate product names too aggressively
- Add to Cart must be clear and easy to tap

Badge rules:

- Use "Refurbished" instead of "Refurb"
- Use "In Stock" instead of "Stock"
- Avoid too many badges
- Do not repeat savings messages
- Prefer one clear discount/savings message

Price rules:

- Main price should be strongest
- Old price should be smaller, grey, and struck through
- Savings should appear once only
- Use KSh formatting consistently

## Single product page recommendations

The product page should build trust and help the customer buy.

Top section should include:

- Large product image or gallery
- Product title
- Condition badge
- Availability badge
- Price
- Old price and savings if available
- Main specs summary
- Add to Cart button
- WhatsApp/contact CTA
- Warranty and delivery reassurance

Specs summary should show, where data exists:

- Processor
- RAM
- Storage
- Display
- Condition
- Warranty
- Availability

Trust near CTA:

- Warranty included
- Tested before dispatch
- Pickup available in Nairobi
- Countrywide delivery available
- WhatsApp support available

Keep checkout and contact flows clear and low-friction. Do not let floating contact controls block the primary purchase action or the most important product details.

Description sections:

- Overview
- Specifications
- Condition
- What's included
- Delivery & Pickup
- Warranty

Do not invent product-specific details that are not in the data.

## Mobile requirements

- Design mobile-first
- Product cards should look clean in two columns
- Image should be dominant
- Text should not feel squeezed
- Buttons must be easy to tap
- Header/trust bar should not take too much screen height
- Floating contact buttons should not block Add to Cart buttons or product cards
