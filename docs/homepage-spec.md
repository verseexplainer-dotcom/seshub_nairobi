# Homepage Spec

The homepage should use existing catalog data first.

## Data Sources

- Featured products: `featured_home`, `featured_rank`
- Category counts: current product catalog
- Product specs: `cpu`, `ram_gb`, `storage_gb`, `storage_type`, `screen_in`
- Stock: `in_stock`, `stock_qty`
- Warranty: `warranty_months`

## Featured Categories

Only show these four featured category cards:

- Laptops
- Smartphones
- Printers
- Desktops

Accessories should remain available through search and category pages, but not as a featured homepage card.

## Sections

- Hero with search and practical CTAs
- Featured category cards
- Featured products grid
- Refurbished vs Brand New comparison
- Deals band
- Shop by brand
- Use case collections
- Trust highlights
- Latest guides preview
- Newsletter signup

All sections should handle empty data without broken UI.

## Copy

Use direct shop-assistant language. Do not use hype, fake urgency, or process-heavy wording.
