# Frontend Rules

- Keep customer-facing copy human, practical, and local.
- Replace process language with direct help language.
- If it sounds like marketing, rewrite it.
- Keep copy short and easy to scan.

## CTA Rules

Use:

- Browse Shop
- Confirm on WhatsApp
- Check availability

Avoid:

- Ask first
- Submit
- Proceed

## WhatsApp

- WhatsApp must feel optional and helpful.
- Present it as a fast way to talk to the team, not as a forced next step.

## Tone

- Sound like a real Nairobi electronics shop.
- Prefer plain wording over polished UX language.
